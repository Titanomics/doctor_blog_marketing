# 네이버 블로그 검색 순위 확인 프로그램 - UI 버전

파스텔톤 브라운 계열의 세련된 디자인으로 제작된 블로그 검색 순위 확인 프로그램입니다.

## 주요 기능

✅ **키워드 검색**: 네이버 블로그 검색 결과에서 특정 키워드 검색
✅ **순위 확인**: 입력한 블로그 주소의 검색 순위 확인
✅ **결과 표시**: 순위, 제목, 링크를 테이블 형태로 표시
✅ **하이라이트**: 일치하는 블로그는 **파스텔톤 노란색**으로 강조
✅ **세련된 디자인**: 파스텔톤 브라운 계열 + Pretendard 폰트

## 설치 방법

### 1. 필수 패키지 설치

```bash
pip install PySide6
```

### 2. Pretendard 폰트 설치

Pretendard 폰트를 시스템에 설치해주세요:
- 다운로드: https://github.com/orioncactus/pretendard/releases
- Windows: 다운로드 후 폰트 파일을 더블클릭하여 설치
- Mac: Font Book에서 설치

## 실행 방법

```bash
python blog_search_ui.py
```

## 사용 방법

1. **검색 키워드 입력**: 검색할 키워드를 입력합니다
2. **블로그 주소 입력**: 순위를 확인할 블로그 URL을 입력합니다
3. **검색하기 버튼 클릭**: 검색을 시작합니다
4. **결과 확인**: 테이블에 표시된 결과를 확인합니다
   - 노란색 배경: 입력한 블로그 주소와 일치하는 결과

```
┌─────────────────────────────────────────────┐
│      네이버 블로그 검색 순위               │
├─────────────────────────────────────────────┤
│  검색 키워드  [________________]           │
│  블로그 주소  [________________]           │
│              [🔍 검색하기]                  │
├─────────────────────────────────────────────┤

│  2위   │  블로그 제목    │  https://...    │ ← 노란색 강조
│  ...   │  ...            │  ...            │
└─────────────────────────────────────────────┘
```

## 디자인 색상 팔레트

- **배경**: `#FAF8F5` (아이보리 화이트)
- **입력 영역**: `#F5EFE7` (파스텔 베이지)
- **버튼**: `#C9A882` (브라운 골드)
- **테이블 헤더**: `#D4C4B0` (연한 브라운)
- **하이라이트**: `#FFFDD0` (파스텔 옐로우)

## 기술 스택

- **UI 프레임워크**: PySide6 (Qt for Python)
- **API**: 네이버 검색 API
- **디자인**: QSS (Qt Style Sheets)
- **폰트**: Pretendard

## 참고 사항

- 네이버 API는 최대 100개까지만 검색 가능합니다
- 검색은 별도 스레드에서 실행되어 UI가 멈추지 않습니다
- 일치하는 블로그가 여러 개일 경우 모두 노란색으로 표시됩니다

## 문제 해결

### 폰트가 적용되지 않는 경우
Pretendard 폰트가 시스템에 설치되어 있는지 확인하세요. 설치되지 않은 경우 기본 시스템 폰트가 사용됩니다.

### API 오류가 발생하는 경우
`blog_search_ui.py` 파일의 CLIENT_ID와 CLIENT_SECRET이 올바른지 확인하세요.
